# 의도 구성

표준화된 단일 활동 가중치 세트는 고객 간에 작동하지 않습니다. 실제 구매 의향을 나타내는 것은 업체마다 다릅니다. 의도 모델을 구성 및 활성화하여 중요한 사항(예: 양식 채우기가 이메일 클릭보다 더 많은 신호를 보내는지 여부)을 지정합니다. 한 가지 글로벌 기본값을 상속하지 않습니다.

**[!UICONTROL 의도 구성]** 패널 도구는 각 리드 의도 활동이 개인의 의도 점수에 대해 계산되는 양을 제어합니다. 이는 의도 점수에 구성 가능한 유일한 입력입니다. 컨텐츠 관련성, 가치 감소 및 임계값과 같은 기타 요소는 시스템에서 관리합니다. [의도 구성 기술](../agents/intent.md#configure-model)을 통해 사용할 수 있습니다.

동료 [채팅 인터페이스](../agents/chat-interface.md)에서 두 가지 방법 중 하나를 사용하여 패널을 엽니다.

* `/intent-configuration` 명령을 입력합니다.
* **[!UICONTROL +]**&#x200B;을(를) 클릭하고 **[!UICONTROL 에이전트 스킬 사용]**&#x200B;을(를) 선택하고 **[!UICONTROL 의도]** 탭을 선택한 다음 **[!UICONTROL 의도 구성]**&#x200B;을(를) 클릭합니다.

![채팅 인터페이스에서 의도 구성 패널을 열었습니다](./assets/intent-configuration-panel.png){width="700" zoomable="yes"}

## 모델 목록 보기

패널에 랜딩 시 총 모델 수가 제목 아래에 있는 **[!UICONTROL 의도 점수 가중치]**&#x200B;와(과) 이름별로 필터링할 검색 필드 및 정렬 가능한 테이블이 표시됩니다.

| 열 | 참고 |
| --- | --- |
| [!UICONTROL 이름] | 정렬 가능, 기본 정렬 |
| [!UICONTROL 상태] | _[!UICONTROL 활성]_(녹색 점), _[!UICONTROL 초안]_(주황색 점), _[!UICONTROL 보관됨]_(회색 점) |
| [!UICONTROL 만든 날짜] | 단축된 전체 날짜 가리키기 |
| [!UICONTROL 마지막으로 업데이트됨] | 단축된 전체 날짜 가리키기 |
| [!UICONTROL 마지막으로 업데이트한 사람] | 사용자 이름이 잘리고, 마우스로 가리키면 전체 이름 |

한 번에 하나의 모델만 _[!UICONTROL 활성]_&#x200B;이 될 수 있으며 이는 채점을 유도하는 모델입니다. 다른 모든 모델은 _[!UICONTROL 초안]_(편집 중, 아직 라이브 상태가 아님) 또는 _[!UICONTROL 보관됨]_(이전 _[!UICONTROL 활성]_ 모델, 새 모델이 활성화되면 자동으로 강등됨) 상태입니다.

행을 클릭하여 모델 세부 사항 보기를 엽니다.

## 모델 세부 사항 보기

세부 사항 보기에는 모델 이름, 상태 배지, 마지막으로 저장된 타임스탬프 및 **[!UICONTROL 의도 점수 가중치]**&#x200B;를 보여주는 탐색 표시와 목록으로 돌아가려면 클릭할 수 있는 모델 이름이 표시됩니다.

세부 사항 보기에는 구매자 의도 활동과 각 활동이 개인의 의도 점수에 기여하는 중요도 수준이 나열됩니다. 활동 카탈로그는 수정되며, 레벨만 변경할 수 있습니다. 이러한 수준은 독립적입니다. 합계를 합산할 필요가 없습니다. 가중치 모델의 한 버전만 한 번에 활성화할 수 있습니다. 변경하려면 현재 버전을 복제하고 복사본을 편집합니다.

![활성 의도 모델에 대한 세부 사항 보기](./assets/intent-configuration-model-detail.png){width="550" zoomable="yes"}

검색 필드는 이름별로 활동 행을 필터링합니다. 테이블 자체:

| [!UICONTROL 의도 활동] | [!UICONTROL AI 제안] | [!UICONTROL 가중치] | [!UICONTROL 재설정] |
| --- | --- | --- | --- |
| 예를 들어, 영업 기회에 추가, 양식 작성, 이메일 클릭, 링크 클릭, 이메일 열기, 이메일 구독 취소, 웹 페이지 방문, 웨비나에서 질문하기, 웨비나에서 에셋 다운로드, 즐거운 순간, 웨비나에서 투표에 응답함, 영업 기회 업데이트 | 읽기 전용 | 드롭다운, 초안 모델에서 편집 가능 | **↺** 아이콘: 이 행을 AI 제안 값으로 다시 설정합니다. |

**가중치 계층**(AI 추천 열과 가중치 열 모두에 대해 동일한 비율):

| 계층 | 값 |
| ---| --- |
| [!UICONTROL 가중치 없음] | 0 |
| [!UICONTROL Trivial] | 30 |
| [!UICONTROL 부] | 40 |
| [!UICONTROL 보통] | 60 |
| [!UICONTROL 중요] | 90 |
| [!UICONTROL 활력] | 100 |

![초안 의도 모델에서 영업 기회에 추가 활동에 대한 값 변경](./assets/intent-configuration-model-edit.png){width="550" zoomable="yes"}

활동을 **[!UICONTROL 가중치 없음]**(0)으로 설정하면 점수를 매기지 않습니다. 시스템은 현재 이 메서드를 사용하여 기본적으로 **[!UICONTROL 이메일 구독 취소]**&#x200B;를 제외합니다.

모든 행을 AI 제안 값으로 복원하려면 표 위에 있는 **[!UICONTROL 모두 제안 값으로 재설정]**&#x200B;을 클릭합니다.

### 모델 만들기 및 활성화

새 가중치 모델을 만들고 활성화하려면 다음 단계를 수행합니다.

1. 기존 _[!UICONTROL 초안]_ 모델에서 시작합니다.

   현재 _[!UICONTROL Active]_ 모델의 **[!UICONTROL 복제]**&#x200B;를 클릭하여 해당 가중치를 새 초안으로 복제할 수도 있습니다.

1. 귀하의 비즈니스에 중요한 사항을 반영하기 위해 가중치를 줄별로 조정하십시오.

   예를 들어, 저신호 활동을 **[!UICONTROL Trivial]**(으)로 다운그레이드하거나, 고신호 활동을 **[!UICONTROL Important]** 또는 **[!UICONTROL Vital]**(으)로 업그레이드하십시오.

1. **[!UICONTROL 저장]**&#x200B;을 클릭합니다.

   저장하면 모델을 즉시 활성화하라는 메시지가 표시됩니다.

1. 활성화를 확인합니다.

확인 결과 새 _[!UICONTROL Active]_ 모델이 만들어지고 이전에 활성화된 모델의 수준을 자동으로 _[!UICONTROL 보관]_(으)로 내립니다. 한 번에 하나의 모델만 활성화할 수 있습니다.

### AI 제안 열

AI 제안 열은 시작점이며, 교육된 권장 사항이 아닙니다.

* LLM 완료 호출 하나는 활동당 하나의 호출이 아닌 테넌트에 대해 모든 활동을 한 번에 처리합니다.

* 각 활동에 대해 모델은 이름과 설명만 읽은 다음 B2B 구매자 행동에 대한 일반적인 지식을 기반으로 가중치 계층을 선택합니다. 예를 들어, 일반적으로 B2B 구매자에게 보내는 **[!UICONTROL 양식 작성]** 또는 **[!UICONTROL 이메일 클릭]**&#x200B;을 고려해 보십시오. 테넌트의 고객 데이터, CRM 레코드 또는 참여 내역 패턴에 대한 액세스 권한이 없으며 현재 테넌트 또는 구독에 특정되지 않습니다.

* 출력은 모델 생성 시 `IBG_INTENT_ACTIVITY_WEIGHT`에서 `SUGGESTED_WEIGHT_VALUE`을(를) 채우고 그 이후에는 정적으로 유지됩니다. 가중치 열을 편집할 때 업데이트되지 않습니다.

* 모든 활동 행에는 항상 채워진 제안 값이 있습니다. 비어 있는 항목이 없습니다.

자신의 비즈니스 컨텍스트를 반영하도록 모든 행을 검토하고 조정합니다. 제안된 값은 튜닝된 모델이 아닌 합리적인 기본값입니다.

## 모델에 대한 작업

상태를 기반으로 모델을 관리할 수 있습니다.

| 액션 | 다음에 사용 가능: | 다음 단계 |
| --- | --- | --- |
| **[!UICONTROL 복제]** | 활성, 초안 | 미리 채워진 이름 필드와 **[!UICONTROL 취소]** 및 **[!UICONTROL 복제]** 단추가 있는 **[!UICONTROL 복제]** 모달을 엽니다. 확인을 수행하면 같은 가중치로 새 _[!UICONTROL 초안]_ 모델이 만들어지며, 이 모델은 세부 사항 보기에서 바로 열립니다. |
| **[!UICONTROL 활성화]** | 초안만(저장 후 바로 메시지로 제공됨) | 초안을 _[!UICONTROL 활성]_(으)로 승격하고 이전의 활성 모델을 _[!UICONTROL 보관됨]_(으)로 자동으로 강등합니다. |
| **[!UICONTROL 삭제]** | 초안만 | 영구적으로 삭제하기 전에 확인 대화 상자를 표시합니다. 이 작업은 취소할 수 없습니다. 활성 모델은 삭제할 수 없습니다. |

초안 모델만 편집할 수 있으므로 일반 워크플로는 현재 _[!UICONTROL 활성]_ 모델에 대해 **[!UICONTROL 복제]**&#x200B;를 클릭하고 초안 복사본에서 가중치를 조정한 다음 **[!UICONTROL 저장]**&#x200B;을 클릭하는 것입니다. **[!UICONTROL 활성화]** 단추를 사용하여 즉시 또는 나중에 활성화할 수 있습니다.

## 의도 점수의 가중치 계산

**[!UICONTROL 가중치]** 열에는 현재 _[!UICONTROL 활성]_ 모델의 행에서 읽은 일일 점수에 사용된 숫자가 표시됩니다. 잠재 고객의 의도 점수를 높이는 데에는 다음 세 가지가 있습니다.

1. 각 활동에 대해 **여기에 구성된 가중치**(`WEIGHT_VALUE`)입니다. AI 제안에서 시작되지만 테넌트별로 재정의할 수 있습니다. _[!UICONTROL Active]_ 모델에 연결된 행만 사용되므로 가중치를 변경하려면 코드 릴리스가 필요하지 않습니다.

1. **콘텐츠 관련성**: 여기에서 구성할 수 없습니다. 시스템은 활동 관련 콘텐츠 또는 에셋에서 키워드를 추출하고 해당 콘텐츠가 키워드, 제품 또는 카테고리와 0에서 1까지 얼마나 잘 일치하는지 점수를 매깁니다.

1. **빈도**: 잠재 고객이 해당 콘텐츠와 상호 작용한 횟수로, 개인의 참여 간 평균에 반영됩니다.

공식적으로 참여당 `activity weight × content relevance`의 평균은 **일별 점수**&#x200B;로 계산되었으며, **7일 지수 감소**&#x200B;가 적용되어 최근 활동이 우세해진 다음 최소-최대값이 현재 모집단에서 0에서 1로 정규화되고 그룹화되었습니다.

| 최종 점수 | 의도 수준 |
| --- | --- |
| > 0.6 | 높음 |
| > 0.2 | 보통 |
| 그렇지 않은 경우 | 낮음 |

### 콘텐츠 관련성

웹 기반 활동의 경우, 시스템은 자산 URL과 관련 회사를 검사한 다음, 해당 회사의 분류법에서 관련 키워드를 도출합니다. 예를 들어 [!DNL Intuit]에 연결된 URL은 _tax_ 또는 _payroll_&#x200B;과 같은 키워드를 표시합니다. 해당 콘텐츠에 대한 잠재 고객의 실제 참여(예: [!DNL TurboTax] 페이지 또는 [!DNL QuickBooks] 페이지 보기)를 해당 키워드와 비교하여 관심 항목이 매핑되는 특정 제품을 결정합니다. _[!UICONTROL 관심 있는 순간]_(오프라인 이벤트 포함)과 같은 웹이 아닌 활동의 경우 모델은 활동 유형이 아닌 오프라인 웨비나 주제와 같은 모멘트의 설명이나 콘텐츠를 평가합니다. 이벤트 범주가 아닌 콘텐츠가 관련성을 결정합니다.

## 알려진 제한 사항

현재 의도 구성에는 다음 제한 사항이 적용됩니다.

* **현재 사용자 지정 또는 테넌트 정의 활동이 없습니다.** 활동 카탈로그가 수정되었으며 [!DNL Marketo Engage]이(가) 유일한 원본 항목입니다. [!DNL Marketo Engage]에 활동을 로그인하여 점수를 매겨야 합니다. 테넌트 정의 활동에 대한 향후 열의 범위가 지정되고 있습니다.
* **현재 타사 의도 수집이 없음**(예: [!DNL Demandbase], [!DNL ZoomInfo] 또는 [!DNL 6sense]). 이 업데이트는 이후 릴리스에 제공될 예정입니다. 그때까지 해결 방법은 해당 신호에 대한 인텐트 점수를 우회하여 서드파티 도구에서 대상자를 빌드하고 [!DNL Marketo Engage] 또는 [!DNL Marketo Optimizer]에 직접 푸시하는 것입니다.
* 가중치 패널 또는 의도 보고서에서 **기본 내보내기 없음**. 보고서 결과를 개인 목록으로 만드는 프롬프트는 [보고서 추가 작업](../agents/intent.md#report-follow-up)을 참조하십시오.
