# 홈 페이지

[!DNL Adobe Marketo Optimizer]의 [!UICONTROL 홈] 페이지를 사용하여 AI 대화를 시작하고 기술을 시작하며 마케팅 작업 영역을 여십시오. 이 페이지로 돌아가려면 탐색에서 **[!UICONTROL 홈]**&#x200B;을(를) 선택하십시오.

개인화된 시작 메시지가 현재 작업에 대해 묻습니다. 대화 입력, 의도 옵션, 빠른 액세스 카드 또는 스킬 카드로 시작하는 방법을 선택합니다.

비디오를 통해 홈페이지 및 마케팅 작업 공간 둘러보기 다음 섹션에서는 서면 지침을 제공합니다.

>[!VIDEO](https://video.tv.adobe.com/v/3505360/?quality=12&learn=on)

## AI 대화 시작

[!UICONTROL 질문하기 또는 작업 시작] 입력을 사용하여 [!UICONTROL 동료] 작업을 시작합니다. 기술 및 명령을 찾아보려면 `/`을(를) 입력하십시오.

1. 질문을 입력하거나 완료할 작업을 설명합니다.
1. 지원 자료를 제공하려면 입력에서 **[!UICONTROL 첨부]**&#x200B;를 선택하고 파일을 첨부하십시오.
1. [!UICONTROL Coworker] 패널에서 계속하려면 프롬프트를 제출하십시오.

홈 페이지에는 작업을 시작하기 위한 4가지 의도 옵션이 있습니다.

| 옵션 | 목표 |
| -------- | ------ |
| [!UICONTROL 계획] | 마케팅 활동 계획 |
| [!UICONTROL 선택 사항에서] | 마케팅 콘텐츠 또는 리소스를 만듭니다. |
| [!UICONTROL 측정] | 마케팅 성과를 검토합니다. |
| [!UICONTROL 최적화] | 기존 마케팅 활동을 구체화합니다. |

자세한 내용은 [채팅 인터페이스](/help/user-guide/agents/chat-interface.md)를 참조하세요.

## 빠른 액세스

[!UICONTROL 빠른 액세스] 카드를 선택하여 작업 영역을 열거나 AI 의사 결정 상태를 검토할 수 있습니다.

| 카드 | 액세스할 수 있는 항목 |
| ------ | --------------------- |
| [AI 의사 결정 상태](/help/user-guide/agents/ai-decisioning-health.md) | 스토리 볼륨 및 담당자별로 분류된 사람의 비율입니다. |
| [마케팅](/help/user-guide/marketing/marketing-management.md) | 마케팅 작업 영역의 프로그램, 개인 여정 및 사용자 목록입니다. |
| [!UICONTROL 자산] | 이메일 및 페이지용 콘텐츠 에셋. |
| [!UICONTROL 보고서] | 성능 및 참여 보고서. |

## 스킬

특정 AI 워크플로를 시작하려면 [!UICONTROL 기술]에서 카드를 선택하십시오.

| 스킬 | 목표 |
| ------- | ------ |
| [!UICONTROL 사용자 기반 대상 만들기] | 사용자 신호 및 그래픽 적합도를 사용하여 대상자를 생성합니다. |
| [!UICONTROL 옴니채널 프로그램 빌드] | 이메일, 웹 및 대상 전반에 걸쳐 프로그램을 간단하게 구성할 수 있습니다. |
| [!UICONTROL 초개인화된 전자 메일 만들기] | 토큰 및 다이내믹 콘텐츠 블록을 사용하여 개인화된 이메일 초안 작성. |
| [!UICONTROL 연결 및 의도 기반 여정 트래픽 제어] | 계정 맞춤 및 의도 신호를 사용하여 여정 간에 연락처를 라우팅합니다. |

[!UICONTROL 동료]에서 에이전트 기술을 찾아볼 수도 있습니다. 이 비디오에서는 검색 필드 및 범주 필터가 있는 [!UICONTROL 에이전트 기술 사용] 대화 상자를 보여 줍니다. 자세한 내용은 [에이전트 기술](/help/user-guide/agents/skills.md)을 참조하세요.

## 작업 공간으로 이동

애플리케이션 탐색을 사용하여 홈 페이지 또는 마케팅 작업 영역에서 다음 작업 영역을 엽니다.

| 작업 영역 | 액세스할 수 있는 항목 |
| ----------- | --------------------- |
| [!UICONTROL 마케팅 관리] | 프로그램, 개인 여정 및 사용자 목록입니다. |
| [!UICONTROL 여정 트래픽 제어] | [여정 트래픽 제어](/help/user-guide/marketing/journey-traffic-control.md). |
| [!UICONTROL 보고서] | 마케팅 성과 보고서. |
| [!UICONTROL 콘텐츠 관리] | [!UICONTROL 템플릿], [!UICONTROL Assets], [!UICONTROL 조각], [!UICONTROL Forms], [!UICONTROL 랜딩 페이지] 및 [!UICONTROL 웨비나]. |
| [!UICONTROL 연결] | [대상](/help/user-guide/audiences/destinations.md). |
| [!UICONTROL Labs] | [채점 스튜디오](/help/user-guide/labs/scoring-studio.md). |
| [!UICONTROL 관리] | [!UICONTROL 채널] 및 [!UICONTROL 프로그램 유형]. |

## 마케팅 작업 영역 살펴보기

탐색에서 **[!UICONTROL 마케팅]** 빠른 액세스 카드 또는 **[!UICONTROL 마케팅 관리]**&#x200B;를 선택하여 마케팅 작업 영역을 엽니다. [!UICONTROL Coworker]와(과) 함께 작업하고 마케팅 리소스를 연 다음 홈 페이지로 돌아가지 않고 최근에 액세스한 항목으로 돌아갑니다.

1. 리소스를 찾아보려면 **[!UICONTROL 마케팅]** 패널에서 **[!UICONTROL 프로그램]**, **[!UICONTROL 개인 여정]** 또는 **[!UICONTROL 사용자 목록]**&#x200B;을 선택하십시오.
1. 리소스를 선택하여 작업 영역 탭에서 엽니다. 또는 **[!UICONTROL 최근에 액세스함]**&#x200B;에서 항목을 선택하십시오.
1. 다른 리소스로 계속 작업하려면 열려 있는 탭 간을 전환합니다.

[!UICONTROL Coworker] 패널에 사용자가 여는 리소스가 반영됩니다. 해당 프롬프트는 선택한 프로그램, 사람 목록 또는 사람을 타겟팅할 수 있습니다. 예를 들어 개인 레코드를 열면 해당 개인의 성향 및 참여 활동을 탐색하기 위한 프롬프트를 제공합니다.

**[!UICONTROL 축소]**&#x200B;를 선택하여 [!UICONTROL Coworker] 패널을 숨기거나 **[!UICONTROL 패널 교체]**&#x200B;를 선택하여 배치를 변경합니다. 자세한 내용은 [마케팅 관리](/help/user-guide/marketing/marketing-management.md) 및 [개인 정보](/help/user-guide/audiences/person-details.md)를 참조하세요.
